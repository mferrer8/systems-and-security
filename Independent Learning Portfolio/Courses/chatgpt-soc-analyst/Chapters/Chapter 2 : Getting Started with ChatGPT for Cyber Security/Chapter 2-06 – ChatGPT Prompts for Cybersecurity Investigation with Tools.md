# Chapter 2-06 – ChatGPT Prompts for Cybersecurity Investigation with Tools

**Status:** Completed  
**Focus:** Using ChatGPT to identify and leverage cybersecurity investigation tools  

---

## Summary
This video demonstrates how ChatGPT can be used to recommend tools for investigating cybersecurity incidents.  
The instructor shows how to generate lists of **free online and paid resources** for analyzing IP addresses, URLs, domains, files, and network traffic.  
ChatGPT is also forgiving with typos in prompts, making it easy to use even for beginners.

---

## Key Takeaways

**Using ChatGPT to Discover Investigation Tools**
- ChatGPT can generate **custom lists of cybersecurity tools** based on specific investigation needs.  
- Example prompt:  
  > "Recommend 20 tools for investigating IP addresses, URLs, domains, and file hashes. Include 3 free online options."  
- Supports exploratory learning by suggesting tools the analyst may not know.  

**Types of Tools Highlighted**
- **File/URL Analysis:** VirusTotal, Hybrid Analysis, Cuckoo Sandbox  
- **Threat Intelligence:** RedCrowd, MISP, GrayNoise  
- **Network Traffic Analysis:** Snort, OpenVAS  
- **Domain/Website Analysis:** URLhaus, CyberChef, FishTank  

**Tool Usage Notes**
- Free tiers exist for many platforms; some require registration.  
- Tools can assist with malware analysis, phishing detection, encrypted commands, and identifying malicious traffic or domains.  
- Analysts can combine multiple tools to get comprehensive insights during an incident.

---

## Notes for SOC Analysts
- Using ChatGPT to generate **tool recommendations** saves time during incident investigations.  
- Always verify the accuracy and reliability of results from online tools.  
- Experiment with different tools to understand which best fit your workflow.  
- Keep a personal reference list of favorite free and open-source resources.  

---

## How ChatGPT Has Changed (2025 Update)
- GPT-5 provides **more detailed and curated tool recommendations**, including current free tiers and widely adopted industry standards.  
- Improved understanding of cybersecurity context allows suggestions **tailored to SOC analyst workflows**.  
- Capable of suggesting **both online and local tool usage scenarios** and integrating multiple types of analysis (files, IPs, domains, URLs) in one response.  
- ChatGPT can now **recognize deprecated tools** and suggest updated alternatives for investigation purposes.
