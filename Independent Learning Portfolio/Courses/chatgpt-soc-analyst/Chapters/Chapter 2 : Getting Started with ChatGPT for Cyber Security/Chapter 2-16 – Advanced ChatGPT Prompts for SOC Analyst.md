## Summary
This video explores advanced prompts that SOC analysts, penetration testers, and cybersecurity professionals can use with ChatGPT. The instructor reviews a GitHub repository of curated prompts, showing how they can be tailored for different roles and scenarios, including code review, incident response, log analysis, penetration testing, technical translation, and workflow generation.

---

## Key Takeaways

**Advanced ChatGPT Prompt Categories**
- **Code Review & Secure Coding**  
  - Role: Network security/code review expert.  
  - Function: Examine code for security flaws and provide guidance on secure practices.  
  - Output: Highlights vulnerabilities, suggests remediation, and explains secure patterns.

- **Incident Response & Log Analysis**  
  - Role: Cybersecurity expert for IR and recovery.  
  - Function: Analyze logs, detect anomalies, and provide best practices for containment and remediation.  
  - Example: Breaking down DNS logs from Cisco Umbrella, highlighting source IPs, suspicious queries, and general event info.

- **Penetration Testing & Network Design**  
  - Includes prompts for network architecture evaluation, web shell development, protocol analysis, and brainstorming attack/defense strategies.

- **Technical Translation & Documentation Assistance**  
  - Translate cybersecurity documentation from Russian or Chinese to English.  
  - Act as a cybersecurity consultant to explain technical content to non-native speakers or less technical stakeholders.

- **Workflow & Visualization**  
  - Generate Mermaid flow diagrams or process flows to document incident response procedures or network architecture.  
  - Useful for reporting, planning, or sharing SOPs with teams.

**Best Practices**
- Read prompts carefully before use to ensure outputs match your intended objective.  
- Customize prompts to your specific scenario (e.g., specific logs, code snippets, incident details).  
- Test outputs in a lab or safe environment before applying recommendations operationally.  
- Explore multiple prompts to see which ones give the most actionable results for your role.  

**Resource Guidance**
- Instructor references a GitHub repository containing curated prompts for cybersecurity tasks.  
- Experimenting with different prompts allows analysts to discover new ways ChatGPT can assist in workflow automation, analysis, and advisory functions.
