# Networking Lab_01 PCAPs

## Overview

All PCAP screenshots and example captures in this repository have been **sanitized** to protect sensitive information.  

- **IP addresses** have been anonymized and replaced with private-range addresses (e.g., `10.0.0.x`).  
- **MAC addresses** and **DNS names** have been replaced with fake or generic values.  
- Packet flows and protocols remain intact, ensuring that the examples are still **realistic and educational**, but no real network data is exposed.  

This repository is safe to view and share, and all screenshots are suitable for documentation or demonstration purposes.  

## Purpose

These sanitized PCAPs are used for:

- Networking tutorials and labs examples
- ICMP, DNS, ARP, and other protocol analysis examples  
- Safe public demonstration of traffic captures without exposing real network data
