# Lab-01 – Network Fundamentals

This lab focuses on learning packet-level networking by capturing and analyzing traffic inside a small virtual environment consisting of three virtual machines. The goal is to build familiarity with core network protocols and how they appear on the wire using `tcpdump` and Wireshark.

## Lab Objectives

* Set up a virtual network environment for traffic analysis
* Capture and analyze ICMP traffic
* Capture and analyze DNS queries and responses
* Capture and analyze ARP requests and replies
* TCP three-way handshake analysis
* Monitor protocol behavior using live packet captures
* Generate traffic manually from command-line tools
* Record captures into `.pcap` files for later analysis
* Strengthen foundational packet analysis skills used in SOC and network troubleshooting workflows

## Tools Used

* `tcpdump`
* Wireshark
* Virtual machines (internal VLAN environment)

This lab serves as the foundation for future protocol and SOC-style traffic analysis labs.
