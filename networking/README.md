# Networking Fundamentals

This directory contains notes, labs, and reference materials on fundamental networking concepts relevant for cybersecurity and SOC analysis. The goal is to document key networking knowledge in a clear, structured way for learning and reference purposes.

---

## Contents

### Notes
- **OSI & TCP/IP Models with Encapsulation**: Explanation of each layer, data units, encapsulation and decapsulation, and relevance for SOC analysis.
- **IP Addressing & Subnetting**: Concepts of IPv4 and IPv6 addressing, subnet masks, CIDR notation, NAT, and public/private IPs.
- **Common Network Protocols**: Overview of key TCP and UDP protocols, their ports, and SOC relevance.
- **Network Devices**: Roles and functions of routers, switches, firewalls, IDS/IPS, proxies, and load balancers.
- **TCP Handshake**: Details of the 3-way handshake, connection teardown, and related SOC considerations.
- **Common Network Attacks**: Description of attacks such as DDoS, ARP spoofing, MITM, port scanning, and how SOC analysts can detect them.
- **Network Monitoring Tools**: Tools such as Wireshark, tcpdump, NetFlow, Nmap, and SIEM platforms, with their use cases.

### Labs & Practice
- **nmap-lab-01.md**: Hands-on lab exploring Nmap network scanning.
- **wireshark-notes.md**: Notes and packet analysis exercises using Wireshark.
- **network-basics.md**: Overview document linking to detailed notes and labs.

---

## Purpose

This directory is designed to:  
1. Serve as a personal reference for networking fundamentals.  
2. Document learning progress in cybersecurity and SOC-relevant networking concepts.  
3. Provide structured notes that can be shared for educational purposes.
