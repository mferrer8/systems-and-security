# Web Fundamentals & Labs

This folder contains notes and supporting materials for web security fundamentals and beginner web labs. It is part of my cybersecurity portfolio and demonstrates hands-on experience with web technologies and basic security testing.

## Purpose

The goal of this folder is to document and organize learning around:

- Understanding how web applications communicate using HTTP/HTTPS
- Familiarity with common web protocols, methods, and status codes
- Performing basic web reconnaissance and enumeration
- Practicing beginner web exploitation techniques (XSS, SQLi, login testing)
- Building a portfolio of web-focused labs for professional presentation

## Objectives Covered

1. Review HTTP basics, request/response structure, and status codes.
2. Conduct basic web reconnaissance using tools like `curl`, `whatweb`, and `nikto`.
3. Complete beginner-friendly web labs (TryHackMe Web Fundamentals, PortSwigger labs).
4. Record findings, observations, and lessons learned in GitHub-ready Markdown files.
